# 出差里程

手機用的出差里程紀錄。用 Safari 打開後可以加入主畫面，像 App 一樣記錄行程停靠點，並計算總公里與國道公里。

網址：<https://weijielin0703-maker.github.io/trip-mileage/>

## 在 iPhone 上加入主畫面

請用 **Safari**（iPhone 上的 Chrome 無法可靠地加入主畫面）。

1. 用 Safari 開啟上面的網址。
2. 點下方的「分享」。
3. 點「加入主畫面」。
4. 之後從主畫面的「出差里程」開啟，並允許定位。

## 怎麼記一趟行程

1. 點「開始行程」。會記錄目前的 GPS 位置當作第一個停靠點。
2. 每到下一個地點，點「記錄這裡」。若當時忘了定位，可改搜尋地址再加入。
3. 停靠點可以改名、刪除、上下調整順序，也可以存成常用地點。之後在 300 公尺內會自動套用該名稱。
4. 點「結束並計算（記錄目前位置）」會先記下目前位置，再計算這一趟。若最後一點已經記過，可改點「只計算（不加點）」。
5. 結果會列出每一段的公里數、總里程，以及國道公里。有填每公里油資時，會一併估油資，並可複製成報帳文字。

至少要有兩個點才能計算。

## 里程從哪裡來

總里程不是兩點間的直線距離。路線來自 [OSRM](https://project-osrm.org/)（Open Source Routing Machine），路網資料是 [OpenStreetMap](https://www.openstreetmap.org/copyright)。國道公里是依路線步驟的路名與道路編號加總（高速公路、國道，以及機場支線、高雄支線、臺中環線、汐止五股高架這類國道名稱）。交流道／匝道預設不計入國道，可在設定裡打開。計算當下需要網路。

## 紀錄存在哪裡

行程、常用地點與設定存在這台手機的瀏覽器裡（IndexedDB，寫不進時改用 localStorage），不會上傳。清除 Safari 網站資料會一併刪除。

- 「匯出 CSV」適合貼到試算表。
- 「匯出 JSON」是完整備份（含常用地點與設定）。
- 「匯入 JSON」會併入尚未存在的行程。

iPhone 的 Safari 常常無法直接下載檔案，匯出時會改為開啟系統分享表單，請選「儲存到檔案」或其他 App。

## 設定

「每公里油資」可留空。有填的話，總里程會乘上這個單價，四捨五入成整數元。
