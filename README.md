# 出差里程

手機用的出差里程紀錄。用 Safari 打開後可以加入主畫面，記錄停靠點，並匯出公司報帳系統要的 Excel。

網址：<https://weijielin0703-maker.github.io/trip-mileage/>

## 在 iPhone 上加入主畫面

請用 **Safari**（iPhone 上的 Chrome 無法可靠地加入主畫面）。

1. 用 Safari 開啟上面的網址。
2. 點下方的「分享」。
3. 點「加入主畫面」。
4. 之後從主畫面的「出差里程」開啟，並允許定位。

## 怎麼記一趟行程

1. 點「開始行程」。會記錄目前的 GPS 位置當作第一個停靠點。
2. 每到下一個地點，點「記錄這裡」。若當時忘了定位，可改搜尋地址再加入。
3. 停靠點可以點名稱改名、刪除、上下調整順序，也可以存成常用地點。之後在 300 公尺內會自動套用該名稱。
4. 填公出日期、時間、洽公對象、事由、停車費。時間預設上午 08:00。
   停車有拿電子發票的話，在「停車發票」按「拍照辨識」拍發票左邊的 QR code，會自動讀出發票號碼、日期、金額和統編，並把金額加進停車費。沒有 QR code 的收據可以按「手動輸入」。照片只拿來辨識，不會存起來。匯出的報帳表會多一個「停車發票」分頁。
5. 點「結束並計算（記錄目前位置）」會先記下目前位置，再計算這一趟。若最後一點已經記過，可改點「只計算（不加點）」。

地址搜尋可以打地標（例如「台北車站」），也可以打完整地址（例如「新北市新店區北新路一段100號」，郵遞區號、樓層、全形數字都可以）。地圖資料裡沒有該門牌時，會改找同一條巷或路，並標示「約略位置（路段）」；長的路段可能離實際地點有段距離，請從結果中挑最近的里。

小店家、停車場這類地點，OpenStreetMap 常常沒有收錄（例如「樂建停車場」），這時搜尋會提醒「沒有叫這個名字的地點」。請改用：

- **地圖選點**：點「地圖選點」，再點地圖或拖曳圖釘到正確位置，按「加入這個點」。如果剛剛搜尋過名稱，會直接用那個名稱。
- **存為常用**：加入後按「存為常用」，之後打部分名稱（例如「樂建」）就會優先找到。
- **貼座標或 Google 地圖連結**：在 Google 地圖長按取得座標（例如 `25.0339, 121.5645`），或貼上網址裡有 `@緯度,經度` 的連結。

至少要有兩個點才能計算。算完的行程會留在「待報帳行程」，依日期由新到舊排列，每筆只顯示一行摘要：日期、時間、總里程、行走里程、路線，以及還沒填的欄位（黃字「待填」）。列表上方有筆數、里程合計和待填筆數。點一筆展開後，可以改欄位、改站名、看地圖與明細、重新計算或刪除整筆。停靠點也可以刪除或用 ↑ ↓ 調整順序，里程會自動重算；重算失敗時停靠點不會變動。每筆至少要留兩個點。

## 匯出公司報帳表

點「匯出公司報帳表 (.xls)」。檔案依公司範本的「匯入頁面」產生，每一列都是文字。iPhone 會開啟分享表單，請選「儲存到檔案」。確認檔案沒問題後，再點「匯出後清空」。

行走里程是國道公里加上交流道、匝道，四捨五入成整數。日總里程是總里程四捨五入成整數。

## 里程從哪裡來

總里程不是直線距離。路線來自 [OSRM](https://project-osrm.org/)，路網是 [OpenStreetMap](https://www.openstreetmap.org/copyright)。計算當下需要網路。

主要伺服器連不上時，會自動改用 FOSSGIS 的備用伺服器（同一份路網資料），兩邊都失敗會再重試一次。仍然失敗時，進行中的行程會保留，之後再按「只計算」即可。

行走里程的判斷方式：

- 路名有「國道」「高速公路」，或是機場支線、五股楊梅高架等國道路段，算國道。
- 編號 1、3 這類道路可能是國道也可能是台線，只有在和國道直接相連、中間沒有轉彎時（例如國道上的橋、高架）才算國道。
- 交流道、匝道只有接到國道時才算，接到市區橋梁的匝道不算。

算完的行程點「明細」可以看到地圖，以及每條計入行走里程的道路和公里數，方便和 Google 地圖對照。

待報帳行程可以點「重新計算」，用目前的規則重算一次（例如舊版算的行程）。里程有變時會先顯示新舊數字，確認後才更新；停靠點和填好的欄位都不會動。

## 紀錄存在哪裡

行程、常用地點與設定存在這台手機的瀏覽器裡（IndexedDB），不會上傳。清除 Safari 網站資料會一併刪除。

## 備份

在「備份」點「匯出備份 (.json)」，選「儲存到檔案」或存到雲端硬碟。換手機或資料不見時，點「匯入備份」選那個檔案。匯入會合併到目前的資料，不會覆蓋，相同的行程也不會重複。備份檔裡有受款人、工號、車號，請不要公開分享。

## 設定

第一次使用時，請在「設定」填受款人、工號、車號，油品（92／95／98）預設 95。填好會自動存在這台手機，之後不用再填；沒填完不能匯出報帳表。程式碼和報帳範本裡不放任何個人資料。

公司、廠區、申請部處、部門、部門代號是固定值，會一併寫進報帳表表頭。
