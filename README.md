# 出差里程

手機用的出差里程紀錄。用 Safari 打開後可以加入主畫面，記錄停靠點，並匯出公司報帳系統要的 Excel。

網址：<https://weijielin0703-maker.github.io/trip-mileage/>

## 在 iPhone 上加入主畫面

請用 **Safari**（iPhone 上的 Chrome 無法可靠地加入主畫面）。

1. 用 Safari 開啟上面的網址。
2. 點下方的「分享」。
3. 點「加入主畫面」。
4. 之後從主畫面的「出差里程」開啟，並允許定位。

## 怎麼記一趟行程

1. 點「開始行程」。會記錄目前的 GPS 位置當作第一個停靠點。
2. 每到下一個地點，點「記錄這裡」。若當時忘了定位，可改搜尋地址再加入。
3. 停靠點可以點名稱改名、刪除、上下調整順序，也可以存成常用地點。之後在 300 公尺內會自動套用該名稱。
4. 填公出日期、時間、洽公對象、事由、停車費。時間預設上午 08:00。
5. 點「結束並計算（記錄目前位置）」會先記下目前位置，再計算這一趟。若最後一點已經記過，可改點「只計算（不加點）」。

至少要有兩個點才能計算。算完的行程會留在「待報帳行程」，還可以改欄位、改站名或刪除。

## 匯出公司報帳表

點「匯出公司報帳表 (.xls)」。檔案依公司範本的「匯入頁面」產生，每一列都是文字。iPhone 會開啟分享表單，請選「儲存到檔案」。確認檔案沒問題後，再點「匯出後清空」。

行走里程是國道公里加上交流道、匝道，四捨五入成整數。日總里程是總里程四捨五入成整數。

## 里程從哪裡來

總里程不是直線距離。路線來自 [OSRM](https://project-osrm.org/)，路網是 [OpenStreetMap](https://www.openstreetmap.org/copyright)。計算當下需要網路。

## 紀錄存在哪裡

行程、常用地點與設定存在這台手機的瀏覽器裡（IndexedDB），不會上傳。清除 Safari 網站資料會一併刪除。

## 設定

可改受款人、工號、車號、油品（92／95／98）。公司、廠區、申請部處、部門、部門代號是固定值，會一併寫進報帳表表頭。
